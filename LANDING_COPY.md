## FAQ
1. How is this different from a generic budgeting calculator?
Planit uses vendor-specific pricing references, plan logic, and API-vs-seat analysis tailored to AI tooling.

2. Does Planit store sensitive company data?
Only audit and lead metadata needed for recommendations are stored; no source code or model prompts are required.

3. What if there are no savings?
Planit returns an explicit no-savings outcome when your current setup is already efficient.

4. Is this free?
Yes, the audit is free. Credex follow-up is optional.

5. How often is pricing updated?
Pricing is versioned and traceable to official vendor pages with verification dates.
